# تقوية Device Ban بدون ظلم أحد

القاعدة الأساسية: لا يُنقل الحظر للجهاز إلا بدليل هوية قوي. الشبكة، الـVPN، الـCGNAT، موديل الجهاز، Canvas، Audio، والبصمات المتصادمة **لا تُعتبر دليلًا** — لا وحدها ولا مجتمعة.

## 1. تصنيف الإشارات إلى ثلاث درجات

| الدرجة | الإشارات | الأثر |
|---|---|---|
| قوية (identity) | native_id (تطبيق أندرويد/iOS)، install_id مُوقّع من السيرفر، device registry link | تكفي لنقل الحظر |
| مساعدة (corroborating) | hardware_hash غير المتصادم، stable_key، استمرارية الجلسات | ترفع الثقة فقط، لا تكفي وحدها |
| ضعيفة (never-ban) | IP، VPN، الشبكة، موديل الجهاز، Canvas، Audio، أي بصمة متصادمة أو generic | وزنها صفر في قرار الحظر |

قاعدة القرار الجديدة: **نقل الحظر يتطلب إشارة قوية واحدة على الأقل غير متصادمة.** بدونها، مهما بلغ المجموع، لا حظر تلقائي.

## 2. طبقة الهوية الجديدة: install_id مُوقّع من السيرفر

كوكي/توكن `HttpOnly` يصدره السيرفر ويوقّعه، ويُخزَّن كذلك في مخزن الجهاز داخل التطبيق. يصمد أمام:
- حذف LocalStorage (الكوكي منفصل)
- تغيير IP / VPN / الشبكة
- Incognito داخل نفس جلسة التطبيق

ولا يصمد أمام مسح كل بيانات الموقع على الويب — وهذا مقبول: عندها نعود لعدم الحظر التلقائي بدل التخمين.

## 3. الهوية الأصلية داخل التطبيق (Android/iOS)

- التطبيق يرسل native id (Android ID / identifierForVendor) عبر السيرفر فقط، ويُربَط بالحساب في `device_identities`.
- إذا كان الـnative id متصادمًا (مرتبط بأكثر من حد معين من المستخدمين، أو من قائمة القيم المعروفة الخاطئة مثل الأصفار أو `9774d56d682e549c`) → يُلغى وزنه كليًا ولا يُعتبر دليلًا.
- عند وجود native id موثوق: حذف الكوكيز أو تغيير المتصفح أو الـIP أو إنشاء حساب جديد **لا يفك الحظر إطلاقًا**.

## 4. بدل الحظر الخاطئ: قائمة «مشتبه به» للمراجعة

جدول جديد `suspected_device_matches` يسجّل الحالات التي فيها ثقة عالية لكن بلا إشارة قوية:
- الحسابان، الدرجة، الإشارات المتطابقة، وقت الرصد، حالة المراجعة (pending / confirmed / dismissed).
- تظهر في لوحة الإدارة كتنبيه فقط. لا يُحظر أحد تلقائيًا منها.
- زر للمشرف: تأكيد (يطبّق الحظر يدويًا) أو رفض (يُسجَّل كاستثناء فلا يُقترح مرة أخرى).

## 5. ما لا يتغير

- الأوزان الحالية تبقى كما هي — لا رفع لوزن stable/noise.
- العتبة 80 و«إشارتان مستقلتان» تبقى للكتم كما هي.
- موككلي (5721f858) لا يُمس إطلاقًا: 0 كتم و0 حظر، ويُتحقق قبل وبعد التنفيذ.

## الاختبارات التي سأجريها

**يجب أن ينتقل الحظر (نفس الجهاز فعليًا):**
1. حذف الكوكيز + LocalStorage
2. حذف بيانات الموقع بالكامل + وجود native id
3. Incognito
4. تغيير المتصفح مع وجود native id
5. تغيير IP
6. VPN
7. تغيير شبكة Wi‑Fi
8. إنشاء حساب جديد على نفس الجهاز

**يجب ألا ينتقل الحظر (بريء):**
9. **الاختبار المطلوب**: نفس Wi‑Fi + نفس IP + نفس VPN + نفس موديل الهاتف + نفس المتصفح، بدون هوية جهاز قوية → لا حظر، فقط `suspected_device_match` للمراجعة
10. جهاز مختلف على نفس الشبكة
11. عدة مستخدمين خلف CGNAT
12. بصمة متصادمة (>10 مستخدمين)
13. generic identity
14. native id متصادم أو من قائمة القيم الخاطئة
15. تغيير المتصفح على الويب بدون native id → لا حظر تلقائي

**تحقق سلامة:**
16. مسح على كل المحظورين حاليًا: كم حساب سيتأثر إضافيًا (المتوقع: فقط من لديه إشارة قوية).
17. حالة موككلي قبل وبعد = 0 / 0 / 0 / 0.

بعد التنفيذ أعطيك تقريرًا بجدول نتائج كل اختبار.
