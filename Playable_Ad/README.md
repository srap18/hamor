# Playable_Ad — إعلان تفاعلي لـ «ملوك القراصنة»

مجلد مستقل تماماً عن اللعبة الأساسية. لا يستورد أي ملف من المشروع ولا يتصل بأي خدمة خارجية.

## التشغيل / المعاينة
افتح `index.html` مباشرة في المتصفح، أو شغّل خادم محلي بسيط:
```
cd Playable_Ad && python3 -m http.server 4321
```

## الرفع على منصات الإعلانات
اضغط المجلد إلى ZIP وارفعه كما هو:
```
zip -r Playable_Ad.zip Playable_Ad
```

## تغيير رابط المتجر (CTA)
في `js/game.js` أعلى الملف:
```js
var CONFIG = {
  DURATION: 25,          // مدة اللعب بالثواني
  STORE_URL: 'https://play.google.com/store/apps/details?id=com.hamor.game',
  GOAL_SHIPS: 8          // عدد السفن لإنهاء الإعلان بالفوز مبكراً
};
```
زر CTA يدعم تلقائياً: `mraid.open` و `ExitApi.exit` (Google/Unity) و `FbPlayableAd.onCTAClick`،
وإن لم يوجد أي منها يفتح `STORE_URL` في نافذة جديدة.

## البنية
```
Playable_Ad/
├── index.html          الهيكل + HUD + التعليمات + شاشة النهاية
├── css/style.css       التصميم والأنيميشن
├── js/game.js          محرك اللعبة (Canvas 2D، 60 FPS)
├── js/audio.js         مؤثرات صوتية مولّدة برمجياً (WebAudio) — 0 KB أصول
└── assets/
    ├── images/         (فارغ — كل الرسوم مرسومة بالكود لخفة الحجم)
    └── audio/          (فارغ — الصوت مولّد برمجياً)
```

## المواصفات المنفّذة
- بحر متحرك بأمواج متعددة الطبقات، غروب، وميض الشمس على الماء، سُحب متحركة.
- تعليمات بصرية (يد متحركة + سهم + نص «اسحب لتوجيه المدفع» / «اضغط لإطلاق النار») تختفي فور أول لمسة.
- تحكم باللمس والماوس: سحب للتصويب، رفع الإصبع لإطلاق النار.
- انفجارات، شرارات، دخان، حلقات صدمة، اهتزاز شاشة، رشّات ماء.
- مؤثرات صوتية قصيرة + زر كتم في الشريط العلوي.
- المدة 25 ثانية أو 8 سفن، ثم شاشة نهاية بالشعار وزر «حمل اللعبة الآن واستمتع!» وزر إعادة اللعب.
- بدون أي طلب شبكة خارجي (مطلوب لسياسة Google Playable Ads).
